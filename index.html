📖 3D Terrain Studio 利用ガイド

🖨️ ① 3Dプリンターで立体造形する手順

  1. お好きな場所を検索（または地図上で範囲指定）し、「3D地形を生成」を押します。
  2. 「起伏の誇張」スライダーでお好みの高低差に調整します（2.0x〜3.5xが模型として見栄えが良くなります）。
  3. 「3Dプリント用STL (バイナリ)」をクリックしてダウンロードします。
  4. Cura, PrusaSlicer, Bambu StudioなどのスライサーソフトでSTLファイルを開くと、自動で底面がフラットに接地し、そのままスライス・印刷できます。

🥽 ② Meta Quest 2（VRゴーグル）で立体視する手順

  1. PCとQuest 2を同じWi-Fi（同一LAN）に接続します。
  2. Quest 2を装着し、内蔵の「Meta Quest Browser」を起動します。
  3. URL欄にPCのローカルIP（例: https://<PCのIP>:5173）を入力してアクセスします。
    ※自己署名証明書の警告が出た場合は「詳細設定」→「アクセスを続行」を選択してください。
  4. 右上の「🥽 VRで見る (Meta Quest 2)」ボタンを押すと、目の前の空中に立体地形模型が浮かび上がります！
  5. コントローラー操作:
    • グリップ / トリガー長押し: 地形模型を手で掴んで空中で自由に回転・移動
    • 両手で掴んで広げる / 縮める: 拡大・縮小（ジオラマサイズ〜巨大スケール）

📱 ③ デスクトップPC・スマートフォンでの操作

  • マウス左ドラッグ / スマホ1本指スワイプ: 360度自由な角度（斜め鳥瞰・見上げ・横等）から立体回転
  • ホイール / ピンチイン・アウト: 拡大・縮小
  • マウス右ドラッグ / スマホ2本指ドラッグ: 平行移動（パン）
  • 「📷 3D画像を保存 (PNG)」: 斜めから眺めた迫力ある地形画像をそのままPNG画像としてダウンロード保存
