# 3D Terrain Studio (3D地形スタジオ)

世界中の国・州・都道府県・山岳地帯の標高データ（DEM）からリアルタイムに3D地形マップを生成し、**① 3Dプリンターでの立体造形（密閉STL）** および **② Meta Quest 2 などのVRゴーグルによる立体没入体験（WebXR）** を実現するWebアプリケーションです。

Cloudflare Workers (Workers Assets) に完全対応しています。

---

## 主な機能

1. **全世界の山谷を立体化（地名検索 & 範囲指定）**
   - 日本国内（富士山、阿蘇カルデラ、北アルプス、屋久島など）や世界各地（グランドキャニオン、マッターホルン、エベレスト、ハワイ島など）のプリセットをワンクリック選択。
   - 検索バーで任意の地名・国名・山名（例:「長野県」「八ヶ岳」「モンブラン」）を検索。
   - 地図上で `Shift + マウスドラッグ` することで自由に切り抜き範囲を指定可能。

2. **PC & モバイル両対応の斜め3Dビューワー**
   - **マウス操作 (PC)**: 左ドラッグで360°回転、ホイールでズーム、右ドラッグでパン。
   - **タッチ操作 (スマホ)**: 1本指で回転、ピンチで拡大縮小、2本指で移動。
   - **視点プリセット**: 「📐 斜め鳥瞰 (45°)」「⬆️ 真上」「➡️ 横アングル」
   - **📷 3D画像を保存 (PNG)**: 斜めから眺めた迫力ある地形画像をワンクリックで高解像度PNG保存。

3. **起伏の誇張（高さ強調スライダー / 0.5x 〜 8.0x）**
   - ゆるやかな山や広域マップでも起伏を際立たせる「高さ強調倍率」スライダーを搭載。
   - スライダーの変更は「3Dプレビュー」「3Dプリンター用STLデータ」「VR立体視」のすべてに即座に反映。

4. **① 3Dプリンター立体造形用エクスポート (3D Print Ready)**
   - 表面の起伏に加え、**四方の側面スカート壁と平坦な底面（ベース）を自動生成して完全密閉ソリッド化**。
   - **STL (バイナリ)**: Cura, PrusaSlicer, Bambu Studio などのスライサーに直接投入可能。
   - **OBJ形式**: カラーテクスチャ付き3Dモデル保存。

5. **② Meta Quest 2 での立体没入体験 (WebXR)**
   - Quest 2の内蔵ブラウザ（Meta Quest Browser）からアクセスして **「🥽 VRで見る」** を押すだけで、目の前の空中に立体地形模型が出現！
   - コントローラー操作（グリップ/トリガーで掴んで回転・移動、両手で拡大縮小）。

---

## 開発・ローカル起動

```bash
npm run dev
```

ブラウザで `http://localhost:5173` を開きます。

---

## 🚀 Cloudflare Workers へのデプロイ

### コマンド一発でデプロイする場合
```bash
npm run deploy
```
*(※ `npm run build` を実行後、Cloudflare Workers に静的アセットとともに自動デプロイされます)*

### GitHub連携で自動デプロイする場合
Cloudflare ダッシュボードの **Workers & Pages** → **Create application** から本リポジトリを連携することで、Git push時に自動デプロイされます。
